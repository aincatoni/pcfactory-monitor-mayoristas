📖 Glosario de Clasificaciones

📋 Total Productos

Todos los productos presentes en el price file de Ingram Micro, sin ningún filtro aplicado. Es el universo completo de referencia.

Price file completo
📊 Con Stock Ingram

Productos que Ingram tiene disponibles para despachar hoy. Son el subconjunto relevante para trabajar.

Available Quantity > 0
🏭 Publicados

Productos que ya están activos en pc Factory como mayoristas en Lista 1. No requieren ninguna acción — ya están funcionando en la web.

mayorista: true lista: "1"
📦 Con Stock PCF

Productos que PCFactory ya tiene en stock propio. Se excluyen porque PCFactory los puede vender directamente, sin necesidad de habilitarlos como mayorista.

stock.aproximado > 0 en PCF
🚫 No Elegibles

Productos que no son elegibles para el canal mayorista porque corresponden a unidades dañadas o reacondicionadas. Se identifican por el texto en el nombre del producto.

NOMBRE contiene "BAD BOX" NOMBRE contiene "OPEN BOX" NOMBRE contiene "CAJA DAÑADA" NOMBRE contiene "CAJA ABIERTA" NOMBRE contiene "CAJA DETERIORADA" NOMBRE contiene "REF" NOMBRE contiene "REFURBISHED" NOMBRE contiene "USADO" NOMBRE contiene "USED"
🎯 Potenciales

Total de productos que podrían publicarse o ya están en proceso. Es la suma de Con Ficha Listos + ID Existente Sin Ficha + ID No Existe y Requieren Creación. Si tienen PCF ID, deben tener lista: "0" y sin stock en PCFactory.

✅ Con Ficha Listos para Publicar

Productos listos para activarse en Lista 1 de forma inmediata. Tienen PCF ID, ficha completa, y no tienen stock propio en PCFactory.

PCF ID en price file mayorista: false stock PCF = 0 Ficha con contenido
⏳ Ficha Solicitada

Productos cuya ficha ya fue solicitada al equipo de eCommerce y está pendiente de publicación. El estado proviene del sheet de seguimiento (Pendiente, Ficha Básica, Ficha Antigua).

PCF ID en price file Ficha vacía en API Con registro en seguimiento
✅ Ficha necesita revisión

Seguimiento marca la ficha como OK pero la API del eCommerce aún la muestra vacía. Posible retraso de caché o indexación. Verificar manualmente si el producto ya puede publicarse.

PCF ID en price file Ficha vacía en API Seguimiento: OK
📝 ID Existente Sin Ficha Solicitada

Productos potenciales cuya ficha está vacía o sin contenido real en el eCommerce. No se pueden publicar hasta que el equipo de contenido complete la descripción.

PCF ID en price file mayorista: false stock PCF = 0 Ficha vacía o incompleta
🆕 ID No Existe y Requieren Creación

Productos cuyo ID no existe aún en PCFactory o que no tienen PCF ID asignado en el price file. Requieren creación del producto en el sistema (proceso de x–x días hábiles).
